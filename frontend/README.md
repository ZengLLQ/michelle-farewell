# Frontend Farewell Michelle

Aplikasi React satu halaman untuk surat personal dengan animasi 3D.

## Perintah

Jalankan dari folder `frontend` dengan Yarn Classic 1.22.22:

```powershell
yarn install --frozen-lockfile
yarn start
yarn build
```

`start` menjalankan development server pada port default 3000. `build` menghasilkan direktori `build/`. Script `yarn test` tersedia, tetapi belum ada test case frontend dalam repository.

Alias `@/` mengarah ke `src/`. Frontend tidak membutuhkan `.env` untuk menampilkan surat dan belum memanggil backend.
